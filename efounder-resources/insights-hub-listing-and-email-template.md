# Note on the Email Template's Fixed Text

Three lines in the email template are fixed text, not merge tags, and were written for the Product Page Conversion Audit:

| Fixed line in the template | Problem | Suggested fix |
|---|---|---|
| Your Checklist is Ready (heading) | Reads wrong for the replies guide | Change to "Your Free Resource is Ready", which fits both |
| Download your checklist and start your first audit today. | "Audit" only fits the product page audit | Change to "Download it now and start today.", or turn it into a new merge tag, {{cta_line}} |
| Download the Checklist (button) | Reads wrong for the replies guide | Change to "Download Now", which fits both |

With these three changes, the template works for every future resource, and only the merge tags change each time.
